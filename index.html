frequently asked questions

about hibi

why hibi instead of obsidian?

obsidian is built around a knowledge base. hibi is a general writing app that can be a knowledge base too. the priority is writing itself: keeping the app fast and letting it fit each person’s workflow, whether you write in markdown, typst, latex, or something else. it’s also open source. think of it as vs code, but for writing.

what is hibi working toward?

one place to write, edit, preview, and organize your writing, that adapts to how you work. being fast is the goal.

who is hibi for?

people who want a simple, powerful writing app without handing over control of their files (ahem, notion).

how does hibi compare to other apps?
  • notion and obsidian: hibi is free and open source, so you’re never locked into one company’s app, and addons let you extend it however you like.
  • typora: hibi is more flexible, with addons and formats beyond markdown.
  • vs code and obsidian: hibi is focused on writing in general, not code or a knowledge base.

the comparison table has the details.

is hibi free?

yes.

what stage is hibi in?

hibi is in beta.

is hibi stable?

bugs, slowdowns, and crashes can happen. addons are especially experimental and still being improved. if something breaks, please file an issue so i can keep track and work on a fix.

if you need a stable app, please check back later. this is a hobby project, so i can’t promise immediate fixes or new features. contributions and pull requests are always welcome.

does hibi have cloud sync?

not yet. hibi sync is coming soon.

using hibi

where are my notes stored?

your notes are saved as files on your computer.

how do i turn on addons?

open settings → addon manager and turn on the ones you want.

where do i download hibi?

the download page has the latest beta for macOS, windows, and linux. nightly builds are on github releases.

something isn’t working.

file an issue on github.

can i request a feature?

open an issue describing what you want. i pick requests up as time and mood allow. if you want yours prioritized, sponsor me on github or open a pull request yourself.

community and contributing

where is the discord?

join it here.

can i use ai to contribute?

yes, ai-assisted contributions are allowed. you still need to understand, review, and test what you submit. see contributing.md.

what else can i contribute to?

the website and the docs are open source too.

how do i make an addon or theme?

start from the addon starter or the theme starter and follow the guide at docs.hibi.garden. you don’t need your own repository to share it: open a pull request to the addons repository, and once it’s reviewed and merged it shows up in hibi’s addon manager and on hibi.garden/addons.
