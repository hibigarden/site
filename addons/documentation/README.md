# Documentation

Export a Markdown workspace as a searchable website saved in one HTML file.

Turn on **Documentation** in **Settings → Addons** and open a workspace. Choose **Export documentation** from the command palette, then choose where to save the file.

See [Exporting](../../../docs/guides/exporting.md) for more options.

## Credits

The exported site uses DOMPurify, MiniSearch, and locally bundled Geist. It includes the licenses for its third-party themes.
