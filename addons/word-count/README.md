# Word count

Turn on **Word count** in **Settings → Addons** to see word and character totals in the status bar.

When the formatted Markdown pane is open, counts leave out formatting characters and note properties. In source view, counts use your current source text, including formatting syntax and properties. Other formats also count their source text. Character totals include spaces and line breaks.

Counts refresh after you pause typing for a quarter of a second. In split view, formatted counts also wait for the preview to catch up with your source edits. The previous totals stay visible while the latest count is calculated or the preview is waiting to update. This delay only affects the displayed counts; your edits and saving continue immediately.
