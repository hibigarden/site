# Import from Notion

In Notion, export as **Markdown & CSV** with subpages and files included. Enable this addon in Hibi, open a Hibi workspace, then choose **File → Import into workspace… → Notion**. Select the ZIP export or its extracted folder.

Pages, attachments, and their folder structure are preserved. Database CSV files also get a Markdown table you can read in Hibi. Views, formulas, permissions, and other Notion application features are not recreated. If the export contains nested ZIP files, extract those first and import the resulting folder.

See [Notion’s export guide](https://www.notion.com/help/export-your-content).
