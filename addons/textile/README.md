# Textile

Turn on **Textile** in **Settings → Addons** to edit `.textile` files. Use source view to write or side-by-side view to see the preview.

Install Pandoc 3.11 or newer and make it available on your system's `PATH` to preview documents and export HTML. Open **Settings → Formats → Textile** to check the installation.

See [Document formats](../../../docs/editing/formats.md) for more help.
