hibi sync

the same workspace on all your computers, with your notes still plain files in your own folders.

what it does

  • your notes stay files

    each computer keeps an ordinary folder. sync copies the files you’ve saved between them through a hibi addon.

    notes
    garden.md
    ideas.md
    journal
    monday.md
    reading.md
    notes
    garden.md
    ideas.md
    journal
    reading.md

  • nothing is overwritten

    when two computers change the same file, your copy stays and the other version is saved beside it, so you choose which to keep.

    notes
    garden.md
    ideas.md
    sync-conflict-3f9a1c0e8b2d4f61-r4.md
    reading.md

  • deletions sync too

    a file you delete goes to the trash on your other computers. if one of them edited it in the meantime, that edit stays.

    notes · other computer
    garden.md
    old-draft.md
    plans.md
    reading.md

  • you choose when

    choose sync workspace now and hibi sends and fetches what changed. the first version doesn’t run in the background.

two ways to run it

  • host it yourself

    an open-source server under the MIT license, for your own workspace. run it on a computer or server you control, behind https.

    $ export HIBI_SYNC_TOKEN=…
$ export HIBI_SYNC_WORKSPACE=notes
$ npm start
Hibi sync listening on loopback.

  • a hosted service planned

    an account on a service that runs the server for you, with the same rules for conflicts and deletions.

what you can do today

hibi is free and works without sync. a workspace is an ordinary folder, so you can already keep it in a git repository and use the built-in git addon to commit, pull and push your notes between computers.

questions

is it end-to-end encrypted?

yes, on the hosted service: your files are encrypted on your computer before they leave it, and only your devices can read them. when you host it yourself, files travel over https to a server you control, so only you can read them.

does it merge changes?

no. when the same file changed on two computers, you get both versions and pick the one to keep.

do i need it to use hibi?

no. hibi stays free and works the same without sync. your notes are plain files either way.

when is it coming?

there’s no date yet.

hear about it first

sync will be announced in hibi’s discord and in the releases on github.
