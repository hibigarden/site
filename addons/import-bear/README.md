# Import from Bear

Export your Bear notes as **TextBundle** to include images, or as **Markdown** for text. Enable this addon in Hibi, open a Hibi workspace, and choose **File → Import into workspace… → Bear**. Select the export folder or ZIP file.

TextBundle assets stay beside their notes. Bear app links are preserved, so those links still open Bear. Your originals stay unchanged.

See [Bear’s export guide](https://bear.app/faq/export-your-notes/).
