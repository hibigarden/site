frequently asked questions

is hibi free?

yes. hibi is free to use.

where are my notes stored?

on your computer, as plain markdown files. open a folder in hibi to browse and edit them.

how do i enable addons?

open settings → addons in the desktop app. enable the tools you need, or build your own with the addon api.

does hibi have cloud sync?

cloud sync is not available in the current alpha. notes are stored locally.

what stage is hibi in?

hibi is currently in alpha. contributions and feedback are welcome.

cloud

cloud features are not available in the current alpha. hibi currently works with local markdown files.
