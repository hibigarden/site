# Import from Obsidian

Enable this addon, open a Hibi workspace, and choose **File → Import into workspace… → Obsidian**. Select your vault folder. Notes and attachments are copied into a new folder; the vault stays unchanged.

Wiki links become relative Markdown links when their target can be identified. Images stay embedded. Embedded notes become links, and ambiguous links are kept for you to review. Vault settings and plugins are not imported.

Obsidian stores notes as Markdown files in a vault. See [Obsidian’s storage guide](https://help.obsidian.md/Files+and+folders/How+Obsidian+stores+data).
